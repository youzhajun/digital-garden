<aside> 💡

视觉格式化模型（高大上的名字），翻译一下就是 html 中各种元素的布局规则。布局规则有以下方式（基础）：

</aside>

- 常规流
- 浮动
- 定位

## 常规流

常规流又称文档流、普通文档流、常规文档流，所有元素默认情况下（不修改元素影响布局规则的属性，如 `float` 等）都属于常规流布局。

总体规则：**块盒独占一行，行盒水平排列。包含块决定了盒子的摆放区域（绝大部分情况下元素的包含块就是父级元素的内容区）**

## 浮动

通过调整元素 `css` 属性中的 `float` 属性可以讲常规流元素设置为浮动元素。`float` 属性有以下几种值：

- `float: none`，默认值，不浮动
- `float: left`，左浮动
- `float: right`，又浮动

### 浮动元素具有以下特点：

- 当一个元素浮动后就变成了**块盒**（可以设置宽高）
- 浮动元素的包含块与常规流块盒一样，都是父元素的内容区

### 浮动元素的排列规则：

- 左浮动的盒子，靠上靠左排列
    
- 右浮动的盒子，靠上靠右排列
    
- 浮动盒子遇到常规流块盒时，浮动元素会避开
    
    ![[视觉格式化模型-1751872129385.png|256x236]]
- 常规流块盒遇到浮动元素时，常规流元素会无视浮动元素（盖到浮动元素上面）
    
- 行盒在排列时，会避开浮动盒子（文字环绕效果，图片浮动，文字为行盒）
    

### 浮动常见问题1：高度坍塌

问题出现原因：

浮动元素的父元素是常规流盒子并且父元素没有设置高度，父元素的高度是有内容决定，但是！常规流计算高度时会忽略浮动元素！这就导致浮动元素作为子元素溢出了父元素的内容区，被称为高度坍塌。

解决方法，设置通用样式。

```css
clearfix::after {
	content: "";
	display: block;
	clear: both;
}
```

<aside> 💡

原理：在高度坍塌的元素中添加一个最后的子元素，并将其设置为块盒，清除浮动，这样会将父元素的高度撑开。

</aside>

## 定位

定位的元素可以手动控制元素在页面中的位置，常规流元素通过 `position` 属性调整为定位元素（元素要么是常规流元素要么是浮动元素要么是定位元素，不可以即有浮动又有定位），`position` 具有以下参数：

- `position：static`。 默认值，不定位。
- `position: relative`。 相对定位。
- `position: absolute`。 绝对定位。
- `position: fixed`。 固定定位。

定位元素可以通过以下属性来调整位置：

- `left: 值`
- `right: 值`
- `top: 值`
- `bottom: 值`

绝对定位、固定定位会脱离文档流，脱离文档流会有以下特点：

- 文档流元素摆放时会忽略脱离文档流的元素
- 文档流元素在计算高度时会忽略脱离文档流的元素

### 相对定位 `position: relative`

**相对定位的元素不会脱离文档流，只是可以任意改变元素的位置，不会影响其他元素。**

使用场景：

- 为绝对定位元素 `position: absolute` 提供包含块

### 绝对定位 `position: absolute`

特点：

- **会脱离文档流**
- 宽高为 auto 时，盒子尺寸适应内容
- 绝对定位元素的包含块变了，包含块变为祖先中最接近的定位元素（position不是static 的元素）找不到的话就是根元素

使用场景：

- 图片上的小图标
- 元素上的漂浮的图片或提示

### 固定定位 `position: fixed`

特点：

- 会脱离文档流
- 宽高为 auto 时，尺寸适应内容
- 包含块变成了**浏览器的可视窗口**

使用场景：

- 顶部固定的导航
- 页面漂浮关不掉的小广告

### 定位常见问题1：定位元素如何实现居中

水平居中：

1. 元素定宽
2. left、right 设置为 0
3. margin-left、margin-right 设置为 0

垂直居中：

1. 元素定高
2. top、bottom 设置为 0
3. margin-top、margin-bottom 设置为 0

### 定位常见问题2：多定位元素重叠时的显示问题

通过设置 z-index 属性来设置显示层级，数值越大越在上层。z-index 可以为负数，如果是负数常规流元素与浮动元素会覆盖定位元素。

# BFC- 块级格式化上下文

<aside> 😀 block formatting context 简称 BFC

</aside>

## 📝 是什么

BFC 是一块独立渲染区，它规定了在该区域中，常规流块盒的布局

- 常规流块盒在水平方向上，必须盛满包含块
- 常规流块盒在垂直方向上，依次摆放
- 常规流块盒若外边距无缝相邻，则进行外边距合并
- 常规流块盒的自动高度和摆放位置，无视浮动元素

## 🤗 如何产生 BFC

由某个 HTML 元素创建，以下元素会在其内部创建 BFC

- 根元素的内部
- 浮动和绝对定位元素的内部
- `overflow` 不等于 `visible` 的**块盒**内部

举个例子：

![[视觉格式化模型-1751872169177.png|894x423]]


- A\C\E\G 处于根元素创建 BFC 容易理解
- B\D\G 处于其父元素创建的 BFC 好理解
- 元素F 向上找找不到 BFC，最终找到根元素，所以元素F处于根元素创建的 BFC 内

总结：**任何一个元素都处于BFC内，父元素没有创建BFC的话会逐级追溯，直到 `html` 元素**

## 特点

- 不同的BFC区域，他们进行渲染时互不干扰
- 创建BFC的元素，隔绝了它内部和外部的联系，内部的渲染不会影响到外部

具体规则如下：

- 创建 BFC 的元素，他的高度会计算浮动元素（解决高度坍塌问题！）
- 创建 BFC 的元素，他的边框盒不会与浮动元素重叠
- 创建 BFC 的元素，不会和他的子元素进行外边距合并（解决外边距合并问题！）

## 📎 作用

### 实战练习1：解决高度坍塌

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>创建BFC的元素，他的自动高度需要计算浮动元素</title>
    <style>
      .container {
        background-color: aqua;
        /* 创建bfc，解决高度坍塌的问题 */
        overflow: hidden;
      }
      .child {
        width: 200px;
        height: 200px;
        /* 浮动之后，父元素高度坍塌了，父元素为自动高度 */
        float: left;
        background-color: red;
      }
    </style>
  </head>
  <body>
    <h2>创建BFC的元素，他的自动高度需要计算浮动元素</h2>
    <h3>父元素创建bfc前后对比</h3>
    <!--  -->
    <div class="container">
      <div class="child"></div>
    </div>
  </body>
</html>
```

### 实战练习2：解决边框盒合并问题

问题：浮动元素与文档流元素合并时，浮动元素会漂浮在文档流元素，此现象为边框盒合并。

解决方式：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>创建BFC的元素 他的边框盒不会与浮动元素合并</title>
    <style>
      .left {
        width: 100px;
        height: 100px;
        background-color: red;
        float: left;
      }
      .main {
        width: 150px;
        height: 150px;
        background-color: green;
        overflow: hidden;
      }
    </style>
  </head>
  <body>
    <div class="left"></div>
    <div class="main"></div>
  </body>
</html>

```

### 实战练习3：解决外边距合并问题

现象：文档流父子块元素在都具有 `margin` 时会进行合并。

解决方法：

方式1： 父元素创建 `BFC`

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>创建BFC的元素它的外边框不会与子元素进行合并</title>
    <style>
      .father {
        width: 200px;
        height: 200px;
        background-color: aqua;
        margin-top: 10px;
        overflow: hidden;
      }
      .child {
        width: 100px;
        height: 100px;
        background-color: red;
        /* 此时外边框合并，取两个值的最大值 */
        margin-top: 190px;
      }
    </style>
  </head>
  <body>
    <div class="father">
      <div class="child"></div>
    </div>
  </body>
</html>

```
