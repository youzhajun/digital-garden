# 概念

归并排序（Merge Sort）是对元素进行排序的一种算法，采用**分治法（Divide and Conquer）**策略：
- 分：将数组递归地拆分成若干子数组（直到每个子数组只剩一个元素）。
- 治：对最小单元的子数组进行排序（单个元素自然有序）
- 合：将有序子数组合并成更大的有序数组（核心操作）

归并排序具有以下特点：
- 稳定排序：相同元素的相对位置保持不变
- **非原地排序**：需要额外空间（空间复杂度O(n)）
- **递归实现**：天然适合递归结构
- **高效性**：时间复杂度稳定为O(n log n)

# 例子

>流程大概如下：


```
原始数组: [38, 27, 43, 3, 9, 82, 10]

分解过程（分）:
1. [38, 27, 43, 3] 和 [9, 82, 10]
2. [38, 27] [43, 3] [9, 82] [10]
3. [38] [27] [43] [3] [9] [82] [10]

合并过程（合）:
1. [27,38] [3,43] [9,82] [10]
2. [3,27,38,43] [9,10,82]
3. [3,9,10,27,38,43,82]
```

> 代码实现

```java
public class MergeSort {

    public static void mergeSort(int[] arr) {
        if (arr == null || arr.length < 2) return;
        int[] temp = new int[arr.length]; // 预分配临时空间
        sort(arr, 0, arr.length - 1, temp);
    }

    // 递归排序
    private static void sort(int[] arr, int left, int right, int[] temp) {
        if (left < right) {
            int mid = left + (right - left) / 2; // 防溢出计算中点
            sort(arr, left, mid, temp);      // 排序左半区
            sort(arr, mid + 1, right, temp); // 排序右半区
            merge(arr, left, mid, right, temp); // 合并两个有序数组
        }
    }

    // 合并两个有序子数组
    private static void merge(int[] arr, int left, int mid, int right, int[] temp) {
        int i = left;    // 左子数组起始指针
        int j = mid + 1; // 右子数组起始指针
        int t = 0;       // 临时数组指针

        // 1. 比较填充临时数组
        while (i <= mid && j <= right) {
            if (arr[i] <= arr[j]) { // 稳定性关键：相等时取左侧元素
                temp[t++] = arr[i++];
            } else {
                temp[t++] = arr[j++];
            }
        }

        // 2. 处理剩余元素
        while (i <= mid) temp[t++] = arr[i++];
        while (j <= right) temp[t++] = arr[j++];

        // 3. 拷贝回原数组
        t = 0;
        while (left <= right) {
            arr[left++] = temp[t++];
        }
    }

    public static void main(String[] args) {
        int[] arr = {38, 27, 43, 3, 9, 82, 10};
        System.out.println("排序前: " + Arrays.toString(arr));
        
        mergeSort(arr);
        
        System.out.println("排序后: " + Arrays.toString(arr));
        // 输出: 排序后: [3, 9, 10, 27, 38, 43, 82]
    }
}
```

> 代码实现（避免递归）

```java
// 迭代实现归并排序
public static void iterativeMergeSort(int[] arr) {
    int n = arr.length;
    int[] temp = new int[n];
    
    // size表示子数组大小，从1开始倍增
    for (int size = 1; size < n; size *= 2) {
        // left表示每个子数组的起始位置
        for (int left = 0; left < n; left += 2 * size) {
            int mid = Math.min(left + size - 1, n - 1);
            int right = Math.min(left + 2 * size - 1, n - 1);
            merge(arr, left, mid, right, temp);
        }
    }
}
```
