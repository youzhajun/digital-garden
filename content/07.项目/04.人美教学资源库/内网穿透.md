# ngrok

[ngrok | API Gateway, Kubernetes Ingress, Webhook Gateway](https://ngrok.com/)

## 安装

微软商店搜索安装 ngrok

## 使用

1. 添加自己的认证

	```
	 ngrok config add-authtoken 33JDE2rFjvRrNatkkLnGNwDNbOD_5DPNFCBjC4rkNrdDnUqZP
	```

2. ngrok http 要往外映射的端口

	```
		ngrok http 8080
		
		// 得到外网访问的地址
		
	```
