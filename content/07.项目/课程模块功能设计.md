# 课程模块功能设计

## 一、基础分类表

### 1. 学段表 **biz_education_stage**

```sql
CREATE TABLE `biz_education_stage` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `tenant_id` varchar(20) NOT NULL COMMENT '租户ID',
  `create_dept` bigint NOT NULL COMMENT '创建部门ID',
  `create_by` bigint NOT NULL COMMENT '创建人ID',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_by` bigint NOT NULL COMMENT '更新人ID',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `del_flag` char(1) NOT NULL DEFAULT '0' COMMENT '删除标记（0-正常，1-逻辑删除）',
  `stage_code` varchar(20) NOT NULL COMMENT '学段编码（PRIMARY-小学，JUNIOR-初中，SENIOR-高中，唯一标识）',
  `stage_name` varchar(50) NOT NULL COMMENT '学段名称（小学/初中/高中，前端展示用）',
  `stage_sort` int NOT NULL DEFAULT 0 COMMENT '排序（数字越小越靠前）',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_tenant_stage_code` (`tenant_id`,`stage_code`,`del_flag`) COMMENT '租户+学段编码唯一'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学段表（固定枚举值，支撑资源的学段分类）';
```

## 二、核心教学资源表

### 1. 教学资源表 biz_teaching_resource（可以理解为一本教材）

```sql
CREATE TABLE `biz_teaching_resource` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID（教材唯一标识）',
  `tenant_id` varchar(20) NOT NULL COMMENT '租户ID',
  `create_dept` bigint NOT NULL COMMENT '创建部门ID',
  `create_by` bigint NOT NULL COMMENT '创建人ID',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_by` bigint NOT NULL COMMENT '更新人ID',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `del_flag` char(1) NOT NULL DEFAULT '0' COMMENT '删除标记（0-正常，1-逻辑删除）',
  `resource_name` varchar(100) NOT NULL COMMENT '教材名称（如“语文（人教版）八年级上册”，前端展示用）',
  `resource_cover` varchar(512) DEFAULT '' COMMENT '教材封面图URL（存储CDN地址，前端展示教材封面）',
  `resource_type` varchar(20) NOT NULL DEFAULT 'TEXTBOOK' COMMENT '资源类型（固定为TEXTBOOK-教材，区分其他资源类型）',
  `subject_id` bigint NOT NULL COMMENT '关联学科ID（关联biz_subject.id，绑定教材所属学科）',
  `version_id` bigint NOT NULL COMMENT '关联版本ID（关联biz_teaching_version.id，绑定教材所属版本）',
  `education_stage_id` bigint NOT NULL COMMENT '关联学段ID（关联biz_education_stage.id，绑定教材所属学段）',
  `grade_id` bigint NOT NULL COMMENT '关联年级ID（关联biz_grade.id，绑定教材所属年级）',
  `volume_id` bigint NOT NULL COMMENT '关联册次ID（关联biz_teaching_volume.id，绑定教材所属册次）',
  `price` decimal(10,2) NOT NULL DEFAULT 0.00 COMMENT '教材价格（0.00表示免费，收费教材需配置金额）',
  `view_count` int NOT NULL DEFAULT 0 COMMENT '累计浏览量（用户访问教材详情页时自动累加）',
  `like_count` int NOT NULL DEFAULT 0 COMMENT '累计点赞量（用户点赞教材时自动累加）',
  `resource_desc` text COMMENT '教材简介（富文本，如“包含10个单元，覆盖小学美术核心知识点”，介绍教材内容）',
  PRIMARY KEY (`id`),
  KEY `idx_resource_category` (`subject_id`,`education_stage_id`,`grade_id`,`volume_id`,`del_flag`) COMMENT '资源分类查询索引（按学科+学段+年级+册次快速筛选教材）'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教学资源表（核心表，对应“教材”，按学科/版本/学段/年级/册次分类）';
```

  `resource_id` bigint NOT NULL COMMENT '关联教材ID（关联biz_teaching_resource.id，绑定单元所属教材）',
  `unit_name` varchar(100) NOT NULL COMMENT '单元名称（如“第二单元 寓言故事”，前端展示用）',
  `unit_sort` int NOT NULL DEFAULT 0 COMMENT '单元排序（数字越小越靠前，如第1单元=1，控制单元展示顺序）',

```sql
举个例子：

场景 1：查询 "苏教版" 的所有资源
SELECT 
  i.resource_id,
  i.resource_type,
  i.resource_name,
  i.cover_url
FROM 
  edu_resource_search_index i
JOIN 
  edu_resource_category_relation r ON i.id = r.index_id AND r.del_flag = '0'
WHERE 
  i.del_flag = '0' 
  AND i.is_searchable = 1
  AND r.version_id = 2 -- 苏教版
GROUP BY 
  i.id -- 去重（同一资源可能属于多个分类）
ORDER BY 
  i.search_weight DESC, i.create_time DESC
LIMIT 0, 20;

场景 2：查询 "语文 + 初中 + 8 年级" 的资源
SELECT 
  i.resource_id,
  i.resource_type,
  i.resource_name
FROM 
  edu_resource_search_index i
JOIN 
  edu_resource_category_relation r ON i.id = r.index_id AND r.del_flag = '0'
WHERE 
  i.del_flag = '0' 
  AND i.is_searchable = 1
  AND r.subject_id = 1 -- 语文
  AND r.education_stage_id = 2 -- 初中
  AND r.grade_id = 8 -- 8年级
GROUP BY 
  i.id
ORDER BY 
  i.search_weight DESC;
  
 场景 3：全文搜索 "愚公移山" 并筛选 "苏教版"
 SELECT 
  i.resource_id,
  i.resource_type,
  i.resource_name,
  i.resource_desc
FROM 
  edu_resource_search_index i
JOIN 
  edu_resource_category_relation r ON i.id = r.index_id AND r.del_flag = '0'
WHERE 
  i.del_flag = '0' 
  AND i.is_searchable = 1
  AND r.version_id = 2 -- 苏教版
  AND MATCH(i.resource_name, i.resource_desc) AGAINST('愚公移山' IN BOOLEAN MODE)
GROUP BY 
  i.id
ORDER BY 
  i.search_weight DESC;

  `audit_status` tinyint NOT NULL DEFAULT 1 COMMENT '审核状态（1-待审核，2-审核通过，3-审核拒绝，仅通过的评论前端展示）',
  `audit_by` bigint DEFAULT 0 COMMENT '审核人ID（关联biz_sys_user.id，管理员账号，记录审核操作人）',
  `audit_time` datetime DEFAULT NULL COMMENT '审核时间（审核操作时自动更新）',
  `comment_like_count` int NOT NULL DEFAULT 0 COMMENT '评论点赞数（用户对评论点赞时自动累加，统计评论热度）',
  PRIMARY KEY (`id`),
  KEY `idx_resource_comment` (`resource_type`,`resource_id`,`audit_status`,`del_flag`) COMMENT '资源-评论查询索引（按资源+审核状态快速查询可展示评论）',
  KEY `idx_parent_comment` (`parent_id`,`del_flag`) COMMENT '父评论-子评论索引（按父评论ID查询子评论，支撑多级评论）'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='资源评论表（支持一级评论，预留多级评论；评论需审核通过后展示）';
```

## 说明

1. 外键关系通过字段注释明确关联表和字段，实际实现中可根据数据库特性选择物理外键或逻辑关联
2. 互动表（浏览/点赞/评论等）均记录用户ID和资源标识，支持用户行为分析和资源热度统计

#  二、管理端完整操作流程

## 1. 基础数据配置

### 1.1 分类体系初始化

1. 登录管理端，进入「系统管理-基础分类」菜单
2. 依次配置：
    - 学段（小学/初中/高中）
    - 年级（1-6年级/7-9年级等，关联对应学段）
    - 学科（语文/数学/英语等）
    - 版本（人教版/苏教版/全国版等）
    - 册次（上册/下册/全册）
3. 每个分类项需设置唯一编码和显示名称，按业务需求排序

### 1.2 管理员账号配置

1. 进入「系统管理-用户管理」菜单
2. 创建管理员账号，分配"超级管理员"角色权限
3. 配置账号状态为"正常"，完成初始化

## 2. 素材资源管理

### 2.1 素材上传

1. 进入「资源管理-素材库」菜单
2. 点击「上传素材」按钮，填写：
    - 素材名称（如"《愚公移山》动画讲解.mp4"）
    - 素材类型（视频/PPT/音频/文档）
	    - 上传文件（系统自动存储到CDN，生成file_url）
    - 素材描述（用于搜索和展示）
    - 封面图（视频/PPT建议上传缩略图）
    - 复用设置（默认允许复用，可设置"仅限当前课程"）
3. 点击「确认上传」，系统将素材信息存入`edu_material_resource`表
4. 自动创建搜索索引（`edu_resource_search_index`，类型为MATERIAL）

### 2.2 素材管理操作

1. 素材列表页支持：
    - 按名称/类型/上传时间筛选
    - 查看素材关联情况（被哪些课程包引用）
    - 编辑素材基本信息（名称/描述/封面等）
    - 禁用/删除素材（已关联的素材禁用后不影响历史引用）
    - 搜索权限控制（设置`is_searchable`属性）

## 3. 教材与课程体系配置

### 3.1 教材创建

1. 进入「教学管理-教材管理」菜单
2. 点击「新增教材」，填写：
    - 教材名称（如"语文（人教版）八年级上册"）
    - 基本属性：选择所属学科、版本、学段、年级、册次
    - 教材封面图
    - 价格设置（0为免费）
    - 教材简介（支持富文本）
3. 提交后系统存入`edu_teaching_resource`表，并创建搜索索引

### 3.2 单元与课程创建

1. 在教材详情页点击「添加单元」：
    - 填写单元名称（如"第二单元 寓言故事"）
    - 设置排序号（按教学顺序）
    - 系统存入`edu_resource_unit`表
2. 在单元详情页点击「添加课程」：
    - 填写课程名称（如"2.1 愚公移山"）
    - 设置排序号
    - 系统存入`edu_course`表

### 3.3 课程资源配置

1. 在课程详情页点击「添加资源」：
    - 选择资源类型（课程包/听力）
    - 填写资源名称（如"愚公移山课程包"）
    - 设置排序号
    - 系统存入`edu_course_resource`表
2. 针对课程包类型资源：
    - 点击「编辑课程包」，填写学习任务清单
    - 上传教案设计文件（支持多个文件）
    - 系统存入`edu_course_package`表
3. 针对听力类型资源：
    - 上传音频文件，填写时长信息
    - 系统存入`edu_course_audio`表

## 4. 素材复用与分类关联（核心流程）

### 4.1 素材绑定到课程包（实现复用）

1. 在课程包编辑页点击「关联素材」按钮：
    - 系统弹出素材选择器，支持按类型/名称搜索
    - 可选择已上传的素材（如"《愚公移山》动画讲解.mp4"）
    - 选择后显示该课程包对应的分类信息（自动从教材继承）：
        - 学科：语文（来自教材的subject_id）
        - 学段：初中（来自教材的education_stage_id）
        - 年级：八年级（来自教材的grade_id）
    - 管理员可微调分类（特殊场景下）
    - 设置素材在课程包内的排序和使用说明（如"用于导入环节"）
2. 点击「确认关联」后，系统执行：
    - 在`edu_course_package_material`表创建关联记录
    - 在`edu_material_package_category`表创建分类映射（继承的分类信息）
    - 同步更新素材搜索索引的category_info字段

### 4.2 跨教材复用同一素材

1. 进入另一版本教材的课程包编辑页（如苏教版语文八年级下册）
2. 重复4.1的操作，选择同一素材（"《愚公移山》动画讲解.mp4"）
3. 系统自动获取当前课程包所属教材的分类信息（语文/初中/八年级）
4. 确认关联后，系统在`edu_material_package_category`表为该素材新增一条分类记录
5. 最终实现：同一素材在不同教材中自动关联对应分类

### 4.3 课后练习配置

1. 在课程包编辑页点击「添加练习」：
    - 选择题型（单选/多选/填空/简答）
    - 填写题目内容、选项、正确答案、解析
    - 设置分值和排序
    - 系统存入`edu_exercise`表，关联当前课程包ID

## 5. 搜索索引管理

### 5.1 索引同步机制

1. 自动同步：
    - 教材/素材创建/修改时自动更新索引表
    - 素材关联到新课程包时，自动更新索引的category_info（追加分类信息）
2. 手动同步：
    - 进入「资源管理-搜索索引」菜单
    - 可按资源类型批量重建索引
    - 支持单独更新某一资源的索引信息

### 5.2 搜索权重配置

1. 在索引管理页，可调整资源的`search_weight`值：
    - 数值范围1-100，默认10
    - 权重越高，搜索结果排名越靠前
    - 支持按资源类型设置默认权重（如教材默认30，素材默认10）

## 6. 内容审核与管理

### 6.1 资源状态管理

1. 支持对教材/单元/课程/素材进行：
    - 启用/禁用（通过del_flag字段控制）
    - 批量操作（如批量隐藏某类素材）
2. 禁用资源自动从搜索结果中移除，不影响已关联内容的历史数据

### 6.2 评论审核

1. 进入「内容管理-评论管理」菜单
2. 审核用户对资源的评论：
    - 通过审核：设置`audit_status=2`，前端可见
    - 拒绝审核：设置`audit_status=3`，前端不可见
3. 支持批量审核和删除违规评论
