# 龙源统一认证
## URL地址

http://xxxxxx.com/api/Authentification/UnityAuth?signkey=*&serviceid=*&loginname=*&nickname=*&realname=*&email=*&redirecturl=*&loginurl=*&logouturl=*

## 参数说明**

**注意：以下参数的值视情况采用UTF-8进行URL编码。**

| 参数名         | 说明                                                                                                                                                                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| signkey     | 必要参数：校验码；英文字母大小写无关。<br>校验码规则：“loginname参数值（非URL编码的值）+ 约定的密钥 + 协调世界时（UTC）年月日时”的MD5哈希值的十六进制字符串。<br>其中：月、日、时不足两位数前面补数字零“0”。<br>例如：loginname参数值为“dragonsource”，约定密钥为“ABC”，当前北京时间为“<br>2015年3月26日 18点30分50秒”。<br>则校验码为：“dragonsourceABC2015032610”的MD5哈希值即：<br>D90EC74492CC8A241AC35CEEDE300424。 |
| serviceid   | 必要参数：由龙源分配的服务编号。                                                                                                                                                                                                                                                                            |
| loginname   | 必要参数：用户登录名。                                                                                                                                                                                                                                                                                 |
| nickname    | 可选参数：用户昵称。                                                                                                                                                                                                                                                                                  |
| realname    | 可选参数：真实姓名。                                                                                                                                                                                                                                                                                  |
| email       | 可选参数：电子邮箱地址。                                                                                                                                                                                                                                                                                |
| redirecturl | 必要参数：认证通过后跳转的URL地址；http://xxxxx.com                                                                                                                                                                                                                                                         |
| loginurl    | 可选参数：认证失败后跳转的URL地址。                                                                                                                                                                                                                                                                         |
| redirecturl | 可选参数：用户点击退出后跳转的URL地址。                                                                                                                                                                                                                                                                       |
