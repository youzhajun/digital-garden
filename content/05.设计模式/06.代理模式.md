# 介绍

**代理模式**是指：**为其他对象提供一种代理以控制对这个对象的访问**。换言之，想要操作什么东西，不需要去直接操作，而是操作中间人。

> 直接找中间人有什么好处？

1. 过滤。假设你不满足背后大佬的某些条件，中间人根本就不告诉你背后大佬的联系方式。（权限校验）
2. 增强。本来你只是个小喽啰，通过中间人的介绍进入了上层圈子。（方法增强）
3. 记录。中间人可以记录你去之前，走之前的状态。（日志记录）


代理模式有三个主要角色：

- Subject：抽象主题（抽象类或接口）
- RealSubject：真实业务（业务类）
- Proxy：代理（对外提供服务）


# 实现

代理模式的分类有：
- 静态代理：编译期指定代理类，结构简单不灵活。
- jdk 动态代理：运行时生成代理类（反射），比如 Spring AOP。
- cglib 代理：运行时创建子类（无需接口），final 类无法代理。

## 静态代理

实现案例：租房通过中介找房东

```java
// 1. 抽象接口（Subject）
public interface Rent {
    void rentHouse();
}

// 2. 真实对象（RealSubject）
public class Landlord implements Rent {
    @Override
    public void rentHouse() {
        System.out.println("房东：我要出租房子！");
    }
}

// 3. 代理对象（Proxy）
public class Agent implements Rent {
    private Landlord landlord;

    public Agent(Landlord landlord) {
        this.landlord = landlord;
    }

    @Override
    public void rentHouse() {
        System.out.println("中介：展示房源、收中介费");
        landlord.rentHouse();
        System.out.println("中介：签合同");
    }
}

// 4. 客户端
public class Client {
    public static void main(String[] args) {
        Landlord landlord = new Landlord();
        Agent agent = new Agent(landlord);  // 通过中介租房
        agent.rentHouse();
    }
}

```

## JDK 动态代理

使用 Java 反射机制在 **运行时** 生成代理类，而不是手动写死。要求：被代理的类必须实现接口。

1. 创建被代理的类与接口

	```java
	public interface OrderService {
	    void placeOrder(String product);
	}
	
	public class OrderServiceImpl implements OrderService {
	    public void placeOrder(String product) {
	        System.out.println("下单产品：" + product);
	    }
	}
	```

2. 创建代理人

	```java
		import java.lang.reflect.InvocationHandler;
		import java.lang.reflect.Method;
		
		public class LogHandler implements InvocationHandler {
		    // 此时被代理对象并不知道是谁
		    private Object target;
		
		    public LogHandler(Object target) {
		        this.target = target;
		    }
		
		    @Override
		    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
		        System.out.println("日志开始...");
		        Object result = method.invoke(target, args);
		        System.out.println("日志结束...");
		        return result;
		    }
		}

	```

3. 使用时 创建动态代理对象

	```java
		import java.lang.reflect.Proxy;

		public class Main {
		    public static void main(String[] args) {
		        OrderService target = new OrderServiceImpl();
		        LogHandler handler = new LogHandler(target);
		
		        OrderService proxy = (OrderService) Proxy.newProxyInstance(
		            target.getClass().getClassLoader(),
		            target.getClass().getInterfaces(),
		            handler
		        );
		
		        proxy.placeOrder("手机");
		    }
		}

	```


## cglib 动态代理

通过**继承目标类**，在子类中织入代理逻辑（使用 ASM 字节码技术）。要求：不能是 final 类，方法不能是 final/private。

1. 引入依赖

	```java
		<dependency>
		  <groupId>cglib</groupId>
		  <artifactId>cglib</artifactId>
		  <version>3.3.0</version>
		</dependency>
	```

2. 真实业务

	```java
		public class ProductService {
		    public void sell(String item) {
		        System.out.println("销售商品：" + item);
		    }
		}
	```

3. 代理对象

	```java
		import net.sf.cglib.proxy.Enhancer;
		import net.sf.cglib.proxy.MethodInterceptor;
		import net.sf.cglib.proxy.MethodProxy;
		
		public class ProductServiceProxy implements MethodInterceptor {
		    private Object target;
		
		    public ProductServiceProxy(Object target) {
		        this.target = target;
		    }
		
		    public Object getProxyInstance() {
		        Enhancer enhancer = new Enhancer();
		        enhancer.setSuperclass(target.getClass()); // 设置父类
		        enhancer.setCallback(this);                // 设置回调方法
		        return enhancer.create();                  // 创建代理对象
		    }
		
		    @Override
		    public Object intercept(Object obj, Method method, Object[] args, MethodProxy proxy) throws Throwable {
		        System.out.println("开始日志...");
		        Object result = proxy.invokeSuper(obj, args);
		        System.out.println("结束日志...");
		        return result;
		    }
		}
	```

4. 使用代理

	```java
		public class Main {
		    public static void main(String[] args) {
		        ProductService target = new ProductService();
		        ProductServiceProxy proxyFactory = new ProductServiceProxy(target);
		
		        ProductService proxy = (ProductService) proxyFactory.getProxyInstance();
		        proxy.sell("笔记本");
		    }
		}
	```
