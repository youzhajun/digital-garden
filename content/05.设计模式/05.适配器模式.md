# 介绍

适配器模式（Adapter Pattern）是一种**结构型设计模式**，允许**接口不兼容的对象相互协作**。

适配器这个名字起的很好，可以将其理解为一个转换头（三孔转两孔）

## 使用场景

- 第三方接口封装
- 老系统迁移
- API 升级兼容
- 多数据源统一

## 实现方式
- 类适配器：通过继承实现（java单继承限制）
- 对象适配器：通过组合实现（推荐）


# 实现步骤

1. 历史方法，需要改造的内容
	```java
		class LegacyUserService {
		    public String getNameById(int id) {
		        return "老用户" + id;
		    }
		}
	```

2. 目标接口

	```java
	interface UserApi {
	    String getUsername(int userId);
	}
	```

3. 适配器

	```java
	class LegacyUserAdapter implements UserApi {
		private LegacyUserService legacy = new LegacyUserService();
	
		public String getUsername(int userId) {
			return legacy.getNameById(userId);
		}
	}
	```

4. 使用

	```java
	
	test() {
		UserApi userApi = new LegacyUserAdapter();  // 客户端不需要知道内部是老接口

        String username = userApi.getUsername(1001);
        System.out.println("获取用户：" + username);
	}
	
	```
