## 介绍

单例模式是一种**创建型模式**，它确保一个类在整个系统中**只有一个实例**，并提供一个全局访问点。

单例模式的两大要点：
-  **构造函数私有化**（防止别人用 `new`）
- **提供静态方法获取唯一实例**

# 实现方式

单例模式的实现方式主要有以下几种：
1. 饿汉式（类加载时就创建）

	```java
		public class Singleton {
		    private static final Singleton instance = new Singleton(); // 立即创建
		
		    private Singleton() {} // 构造函数私有
		
		    public static Singleton getInstance() {
		        return instance;
		    }
		}

	```

2. 懒汉式（需要时才创建）
	```java
		public class Singleton2 {  
		    private static Singleton2 instance;  
		  
		    private Singleton2() {}  
		  
		    public static Singleton2 getInstance() {  
		        if (instance == null) {  // 多线程下可能出错  
		            instance = new Singleton2();  
		        }  
		        return instance;  
		    }  
		}
	```


- 懒汉式 - 线程安全
	```java
	
	public class Singleton {
	    private static Singleton instance;
	
	    private Singleton() {}


		// 锁静态方法，相当于锁了整个类
	    public static synchronized Singleton getInstance() {
	        if (instance == null) {
	            instance = new Singleton(); // 只有第一次才进来
	        }
	        return instance;
	    }
	}
	
```


- 双重检查锁定。兼顾性能与线程安全

	```java
		public class Singleton {
		    private static volatile Singleton instance; // volatile防止指令重排
		
		    private Singleton() {}
		
		    public static Singleton getInstance() {
		        if (instance == null) {
		            synchronized (Singleton.class) { // 只在第一次加锁
		                if (instance == null) {
		                    instance = new Singleton();
		                }
		            }
		        }
		        return instance;
		    }
		}

	```

- 静态内部类（懒加载 + 线程安全 ✅✅）

	```java
		public class Singleton {
		    private Singleton() {}
		
		    private static class Holder {
		        private static final Singleton INSTANCE = new Singleton(); // 类加载时初始化
		    }
		
		    public static Singleton getInstance() {
		        return Holder.INSTANCE;
		    }
		}

	```


- 枚举单例（最安全）

```java
	public enum Singleton {
	    INSTANCE;
	
	    public void doSomething() {
	        System.out.println("执行单例方法");
	    }
	}
```

# 业务场景

适用于只需加载1次的配置或只能拥有1个实例的类。
- 配置管理器
- 线程池管理器
- 数据库连接池

> 在 `spring` 环境中不要手写单例，使用 `@Compoent` 即可
