# 介绍

**原型模式**是一种创建型设计模式，**通过复制已有对象来创建新对象**，而不是通过 `new` 关键字重新实例化。它的核心在于：**通过对象自身的 `clone()` 方法来复制一个一模一样的新对象**。

## 适用场景

1. 对象创建开销大，如数据结构复杂、初始化过程复杂
2. 需要大量创建相似的对象
3. 需要保留原始对象的状态

# 实现

Java 的原型模式依赖于 `java.lang.Cloneable` 接口和 `Object` 类的 `clone()` 方法。

步骤：
1. 实体类上实现 `Cloneable` 接口，重写 `clone` 方法
	
	```java
		public class Resume implements Cloneable {
		    private String name;
		    private int age;
		    private String experience;
		
		    public Resume(String name, int age, String experience) {
		        this.name = name;
		        this.age = age;
		        this.experience = experience;
		    }
		
		    public void setExperience(String experience) {
		        this.experience = experience;
		    }
		
		    @Override
		    public Resume clone() {
		        try {
		            return (Resume) super.clone();  // 注意！！！此处是浅拷贝
		        } catch (CloneNotSupportedException e) {
		            throw new RuntimeException(e);
		        }
		    }
		
		    public void show() {
		        System.out.println("姓名：" + name + " 年龄：" + age + " 经验：" + experience);
		    }
		}

	```

2. 使用 `clone()` 创建多个对象
	
	```java
		public class Main {
		    public static void main(String[] args) {
		        Resume origin = new Resume("小张", 25, "Java开发 2年");
		        Resume copy1 = origin.clone();
		        Resume copy2 = origin.clone();
		
		        copy1.setExperience("Java开发 3年");
		        copy2.setExperience("转岗前端 1年");
		
		        origin.show();   // 小张 25 Java开发 2年
		        copy1.show();    // 小张 25 Java开发 3年
		        copy2.show();    // 小张 25 转岗前端 1年
		    }
		}

	```

> 注意！`clone()` 只是浅克隆当 `Resume` 类中有引用对象时就会出现问题！

举个例子，`Resume` 中有 `Experience` 工作经历 引用对象，clone 时依旧使用 `clone()` 浅拷贝

```java
// 工作经历
class Resume implements Cloneable {
    private String name;
    private Experience experience; // 这是引用类型

    public Resume(String name, String company) {
        this.name = name;
        this.experience = new Experience(company);
    }

    public void setCompany(String company) {
        this.experience.company = company;
    }

    @Override
    public Resume clone() {
        try {
            return (Resume) super.clone(); // 浅拷贝
        } catch (CloneNotSupportedException e) {
            throw new RuntimeException(e);
        }
    }

    public void show() {
        System.out.println("姓名：" + name + " 公司：" + experience.company);
    }
}

class Experience {
    String company;
    public Experience(String company) {
        this.company = company;
    }
}


```

使用时就会出现问题，会发现多个对象中的 `Experience` 属性指向的其实是一个地址：

```java
public class Main {
    public static void main(String[] args) {
        Resume origin = new Resume("小张", "阿里巴巴");
        Resume copy = origin.clone();

        copy.setCompany("腾讯");

        origin.show(); // ❗ 公司：腾讯
        copy.show();   // 公司：腾讯
    }
}

```

此处出现的问题就在于 `clone()` 方法实现的是浅拷贝，即：只拷贝了该对象的地址值，两个变量指向的同一个地址值。
