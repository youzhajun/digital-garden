# 介绍

建造者模式是一种**创建型设计模式**，用于**将一个复杂对象的构建过程和它的表示（结构）分离**，从而可以灵活构建不同类型的对象。

如果你是一名经历过实际项目开发的开发者，那么估计你肯定了解过`Lombok`、`okhttp` 等工具，其中他们也都用到了建造者模式，如 `lombok` 的 `@Builder` 、`okhttp` 中的 `new Request.Builder()`


场景类比：造房子
- 造一栋房子很复杂，有地基、墙、屋顶、窗户、电路等步骤
- 每种房子（别墅、高楼）建造顺序可能一样，但细节不一样
- 所以我们需要一个 **Builder** 专门负责“如何一步步构建房子”
- 再配一个 **Director** 控制“构建的顺序”


# 案例

## 要求

设计一个用户注册对象，包含以下字段：
- 用户名（必填）
- 密码（必填）
- 年龄（可填）
- 地址（可填）
- 手机号（可填）

如果使用传统构造函数，要么需要全参构造、要么就1个个进行 set。此时可以用到建造者模式与内部静态 `Builder` 类

```java
public class User {
    private String username;
    private String password;
    private int age;
    private String address;
    private String phone;

    // 私有构造函数
    private User(Builder builder) {
        this.username = builder.username;
        this.password = builder.password;
        this.age = builder.age;
        this.address = builder.address;
        this.phone = builder.phone;
    }

    // 静态内部类 Builder
    public static class Builder {
        private String username;
        private String password;
        private int age;
        private String address;
        private String phone;

		// 调用此构造时 必须传入用户名与密码
        public Builder(String username, String password) {
            this.username = username;
            this.password = password;
        }

        public Builder age(int age) {
            this.age = age;
            return this;
        }

        public Builder address(String address) {
            this.address = address;
            return this;
        }

        public Builder phone(String phone) {
            this.phone = phone;
            return this;
        }

        public User build() {
            return new User(this);
        }
    }

    @Override
    public String toString() {
        return "User{" +
                "username='" + username + '\'' +
                ", password='" + password + '\'' +
                ", age=" + age +
                ", address='" + address + '\'' +
                ", phone='" + phone + '\'' +
                '}';
    }
}

```

使用：
```java
public class Main {
    public static void main(String[] args) {
        User user = new User.Builder("tom", "123456")
                .age(20)
                .address("Shanghai")
                .build();

        System.out.println(user);
    }
}

```
